# light-mark

موقع بصمة ضوء — BASMAT DAW STUDIO، للإنتاج الإعلامي وصناعة المحتوى في الكويت.

## ملفات الموقع

`index.html` موجود في جذر المستودع، وبجواره `styles.css` و`app.js` و`content.js` ومجلد `assets/` الذي يضم الصور والخط العربي والفيديوهات الـ٢٢ كاملة. الموقع ثابت ولا يحتاج npm أو خطوة بناء أو قاعدة بيانات.

يتضمن الخدمات، مساعد تجهيز طلب عرض السعر، معرض الأعمال، وقسم إعلانات الأغذية والألبان بالذكاء الاصطناعي، واختيار واتساب الكويت أو أمريكا. الفيديوهات تبدأ عند الضغط فقط، ويُوقف أي فيديو آخر يعمل في الصفحة.

## تعديل المحتوى

- `content.js`: بيانات الشركة، أرقام واتساب، النصوص، الخدمات، خيارات مساعد الطلب، الأعمال في `works`، وإعلانات الذكاء الاصطناعي في `aiAds.videos`.
- `index.html`: هيكل الصفحة والنصوص الثابتة.
- `styles.css`: الألوان والخط وتخطيطات الموبايل والكمبيوتر.
- `app.js`: منطق المساعد، التشغيل عند الضغط، اختيار رقم واتساب، وتجهيز الرسائل.
- `assets/works/`: الفيديوهات الثمانية في «نماذج من شغلنا» وصور معاينتها.
- `assets/ai-food/`: فيديوهات إعلانات AI الثلاثة عشر وصور معاينتها. المقطع الثامن منها يعرض عطرًا، ووصفه يطابق محتواه.
- `assets/fashion/`: فيديو قسم «الأزياء والموضة» وصورة معاينته. يمكن تعديل العنوان والوصف وإضافة فيديوهات لاحقًا في `fashion.videos` داخل `content.js`. يظهر القسم بعد إعلانات AI وقبل مساعد الطلب، وزره يتيح اختيار واتساب الكويت أو أمريكا مع رسالة عن إعلان أزياء.

رقم الكويت `96560979388` ورقم أمريكا `19492573300` في روابط واتساب. يظهر الأمريكي للزائر بالشكل `+1 (949) 257-3300`. كل رقم له نفس رسالة الطلب؛ العميل يضغط إرسال داخل واتساب.

## تشغيل محلي

```bash
python3 -m http.server 8080
```

افتح `http://localhost:8080`.

ملف `CNAME` وإعدادات الدومين وGitHub Pages وDNS محفوظة كما هي. تحديث المحتوى يتم بعمل commit وpush إلى `main`.
